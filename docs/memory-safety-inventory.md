# Memory Safety Inventory

This inventory names the memory-risky boundaries that accept untrusted bytes,
untrusted lengths, or externally owned resources. Each row has a live
`test_command`; rows without one are rejected by `make check-memory-safety-inventory`.

| boundary | trusted input | maximum length | ownership or lifetime rule | cleanup path | test_command |
| --- | --- | --- | --- | --- | --- |
| ELF image loading | Initramfs module image and ELF program/section headers are untrusted until range validation succeeds. | File offsets are bounded by the module size; virtual ranges are checked for overflow and page rounding. | Loader uses copied metadata only after range validation; no user pointer is retained. | Reject the image before process address-space commit. | `make host-tests` |
| initramfs CPIO parsing | The boot archive is trusted only after `cpio_iterate()` validates newc headers and file extents. | Header and file payload stay within the archive byte span. | Parser returns bounded slices into the immutable initramfs image. | Stop iteration and reject malformed entries without allocating process state. | `make host-sanitize` |
| romfs block decoding | The romfs service treats disk blocks, inode fields, directory entries, and indirect block numbers as untrusted. | Block numbers and file offsets are bounded by the mounted image and fixed block size. | OCBs own cached inode/path state; reads copy into caller-provided message buffers only after size checks. | Mount fails or the individual read/name lookup returns an error without keeping partial state. | `make host-sanitize` |
| user-copy and xfer vectors | User IOV bases and lengths in IPC/message copy paths are untrusted. | IOV count and summed byte length are bounded before copy; overflow is rejected. | Copy helpers validate access for the active process and do not retain user pointers after the call. | Failed validation aborts the transfer before side effects are committed. | `make host-sanitize` |
| IPC message marshalling | Message headers, native transfer counts, and capability-transfer vectors are untrusted. | Native cap transfer is bounded by `_IO_NATIVE_CAP_TRANSFER_MAX`; message sizes are bounded by the receive context. | Received caps are allocated all-or-nothing and attenuated; partial transfer allocation is rolled back. | Malformed transfers fail closed and leave no leaked capability slot. | `make check-capability-law` |
| path handling | Connect paths, normalized paths, and LKL filesystem joins are untrusted strings. | Paths are bounded by `PATH_MAX`, received message length, or destination buffer size. | Path builders copy into fixed destination buffers and reject traversal outside their root. | Reject bad paths before attaching OCBs or reserving scarce server slots. | `make host-sanitize` |
| DMA and MMIO mapping | Device-reported MMIO ranges, delegated resources, and DMA buffer sizes are untrusted hardware-boundary data. | Delegation counts use fixed message maxima; DMA allocation sizes are capped by the virtio/LKL pool. | Drivers keep DMA pages owned by the service and seal MAP_PHYS authority after delegation. | Release leftover delegated resources and reject direct/self-claimed MMIO paths. | `make check-map-phys-inventory` |
| service restart and stale handles | Restarted servers, stale endpoint handles, and crashed LKL domains are untrusted recovery states. | Restart probes use bounded workloads and fixed service paths. | Supervisor/restart paths must not reuse stale endpoints or keep old DMA/MMIO authority. | Crash/restart tests require surviving services to keep working and stale handles to fail closed. | `make check-lkl-containment` |
