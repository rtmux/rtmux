# preempt-inventory.txt - classification of every long or unbounded loop in the
# scanned kernel subsystems, checked by scripts/preempt-inventory.sh
# (make check-preempt-inventory). One record per candidate loop:
#
#   class <TAB> file <TAB> function <TAB> normalized-loop-text <TAB> reason
#
# class is bounded, checkpointed, irqoff, peer_dependent, or input_dependent; the
# script header defines each class and the fields its reason must carry
# (bound:/cap:, checkpoint:, lock:, waits-for: and holds:, input: and review:).
# The file, enclosing function, and normalized loop text (the joined header for
# a multiline while/for) form the multiset key; the reason is documentation but
# the check rejects a missing field, "unaudited", and "TODO". Regenerate after
# adding, removing, or editing a candidate loop:  make preempt-inventory-update
# then replace each UNCLASSIFIED line with a real preemption story.
#
